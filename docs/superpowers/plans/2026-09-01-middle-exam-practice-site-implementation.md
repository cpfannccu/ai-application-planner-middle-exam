# 中級題庫網站實作計畫

## 階段 1：來源盤點與轉換管線

1. 讀取六份 PDF 的頁數、文字層、圖片物件與版面座標。
2. 建立可重複執行的 PDF 題目擷取程式。
3. 依題號切分題幹、選項、答案、來源頁碼與必要圖片。
4. 對複雜排版題目輸出題目區域截圖。
5. 產生標準化中間資料並執行題數、ID、選項與答案檢核。

## 階段 2：資料輸出

1. 產生網站使用的 `questions.json`。
2. 產生六份 UTF-8 BOM CSV。
3. 以 `@oai/artifact-tool` 建立整合 Excel。
4. 驗證 JSON、CSV、Excel 的核心資料一致。
5. 渲染並檢查 Excel 所有工作表。

## 階段 3：靜態網站

1. 建立首頁與題庫載入／驗證流程。
2. 建立即時練習、模擬考試、錯題複習三種模式。
3. 實作完整試卷及跨年度 10／20／50 題抽題。
4. 實作專注單題、題號面板、圖片顯示與響應式介面。
5. 實作 `localStorage` 續答、錯題熟練度、歷史成績與匯入／匯出。
6. 加入來源及非官方網站聲明。

## 階段 4：驗證與 GitHub Pages

1. 執行題庫 schema 與資產路徑檢查。
2. 執行 JavaScript 單元／流程測試。
3. 在本機靜態伺服器測試網站。
4. 檢查 320px 手機與桌面版面。
5. 建立 GitHub Pages 靜態部署設定與操作說明。
6. 提交所有成果；實際建立遠端 GitHub 儲存庫與公開網址需使用者帳號授權。
